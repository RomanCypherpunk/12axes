# Spec: Change the design of the website to look more Football-like
# Status: Phase 1 done, Phase 2 pending

## Overview
A football fan enters the website. All he sees is the exact copy of a 12 axes project. He doesnt like it and leave. That's not how it should be done. The user should see a UI and UX that remembers him of football in the colors and how its built.

The work is done in two phases, one after the other. Phase 1 must be finished before Phase 2 starts, so the re-skin only has to touch one place.

## In scope

### Phase 1 — Centralize the colours
- Remove hard-coded colours from the stylesheets (app.css, editorial.css, motion.css) and replace them with tokens
- Merge near-duplicate colours into a smaller set of tokens, for consistency between pages
- Move the dark theme colours (currently at the end of app.css) into their own file, clearly labelled as the dark theme colour base
- Move the PDF report palette (currently in report.css) into tokens.css

### Phase 2 — Football re-skin
- Modify the overall design of the website, including colors, UI/UX more in line with what football fans know and recognize
- Predominant pitch green palette, in the spirit of New Star Soccer
- Football imagery: field lines, corner arc, penalty box, especially on the first view of the website
- Footballs as visual elements

## Out of scope
- The content should not be adapted to football. That's for a later stage


## Non-functional
- [NFR-001] => Design should look footballish, with a predominant of (pitch) green color
- [NFR-002] => Follow good design practice: text must meet WCAG contrast (4.5:1 normal text, 3:1 large text)
