# Introduction

This project aims to be a version of 12 Axes but for Football (understand soccer, you lazy ass yankee) and more specifically for Football managers/coaches

The ideia is to develop an algorithm that fits football ideias into football philosophies and educate the user on what his or her sports views aligns to

# Inspirations

This project is mainly inspired in 3 main projects:
- 12 axes (original): https://github.com/politicaltests/politicaltests.github.io/tree/main => I'm not exactly sure if this is really the original one, but it was the one I tracked down to be the oldest one. Based on a number of questions, it fits the user in 12 (i guess?) political boxes
- 12 axes (most recent website): https://12axes.vercel.app/ => It seems to be an upgraded version on the original 12 axes. You're not only fitted into an ideological box, but also has similarities with other. This project is a fork of the 12 axes website, and the ideia is to build upon it
- Copero Ideologia Futbolistica: https://copero.com.ar/juegos/ideologia-futbolistica. It's an early ideia on what I said, but way simpler. It has basically 2 axes
